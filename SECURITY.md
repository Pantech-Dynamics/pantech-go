# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to
[security@pantechdynamics.com](mailto:security@pantechdynamics.com). **Do not open a public GitHub
issue, discussion or pull request** for a suspected vulnerability.

Include as much of the following as you can:

- the SDK version and how you use it;
- a description of the issue and its impact;
- steps or a minimal example to reproduce it.

We will acknowledge your report within three business days, keep you informed while we work on a
fix, and credit you in the release notes if you would like. Please give us a reasonable amount of
time to release a fix before any public disclosure.

Never include real API keys or customer data in a report. If a key may have been exposed, revoke
it in the Pantech console straight away.

## Supported versions

Security fixes are released for the latest minor version of the SDK.

| Version | Supported |
| ------- | --------- |
| v0.1.x (latest) | Yes |
| Older | No |
